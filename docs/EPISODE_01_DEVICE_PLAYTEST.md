# Episode 1 Galaxy 태블릿 전체 플레이 체크리스트

- 대상: Episode 1 「사라진 별빛 씨앗」 P0~P5, 최종 추리와 보상
- 기기: Galaxy 태블릿
- 브라우저: Chrome 데스크톱 모드
- 목표 시간: 처음 플레이 기준 8~12분

## 1. 테스트 전 준비

1. Codespaces에서 `main` 브랜치가 최신 상태인지 확인한다.
2. 앱을 실행하고 Chrome에서 전달된 포트를 연다.
3. Home 화면의 현재 누적 XP와 완료한 모험 횟수를 메모한다.
4. 화면을 먼저 세로 방향으로 두고 시작한다.
5. 개발 메뉴에서 `새 방탈출 Episode 1 전체 체험`을 선택한다.

## 2. 전체 진행 확인

### P0 — 떨어진 별조각

- 받침대 아래의 반달 별조각이 쉽게 보이는지 확인한다.
- 별조각을 누르면 받침대 홈으로 이동하는지 확인한다.
- 이동 중 다른 오브젝트가 눌리지 않는지 확인한다.
- 결합 후 받침대 확대 조사가 가능한지 확인한다.

### P1 — 별받침대 균형 장치

- 별가루가 총 12개로 표시되는지 확인한다.
- 먼저 `5·4·3`처럼 불균형하게 배치한다.
- 벌점이나 초기화 없이 빼기·더하기로 수정되는지 확인한다.
- `4·4·4`에서만 장치가 작동하는지 확인한다.
- 별무늬 렌즈가 인벤토리에 들어오는지 확인한다.
- 연못과 시계꽃 숲의 잠긴 별길이 열리는지 확인한다.

### P2 — 시계꽃 시간고리

- 파란 꽃은 4칸, 노란 꽃은 6칸 주기라는 설명이 이해되는지 확인한다.
- 4번을 눌러 파란 꽃만 반응하는지 확인한다.
- 6번을 눌러 노란 꽃만 반응하는지 확인한다.
- 12번에서 두 꽃이 함께 피는지 확인한다.
- 은빛 바람끈이 인벤토리에 추가되는지 확인한다.

### P3 — 연못 기억 흔적

- 별무늬 렌즈를 선택하지 않고 돌거울을 눌러 본다.
- 렌즈 선택 안내가 나오고 아이템이 사라지지 않는지 확인한다.
- 렌즈를 선택해 돌거울에 설치한다.
- 바람 자국을 먼저 눌러 구체적인 오답 안내가 나오는지 확인한다.
- 실제 발자국을 `0 → 2 → 4 → 6` 순서로 선택한다.
- 젖은 발자국 단서가 수첩에 기록되는지 확인한다.

### P4 — 분수대 연쇄 장치

- 은빛 바람끈을 선택해 바람바퀴를 수리한다.
- 잘못된 아이템을 사용할 때 아이템이 보존되는지 확인한다.
- 연못 단서 없이 돌을 고를 수 없다는 안내가 자연스러운지 확인한다.
- 세 번째 돌에서 별열쇠가 나타나는지 확인한다.
- 별열쇠를 직접 챙긴 뒤 관리 상자에 사용하는지 확인한다.
- 달빛 손잡이가 인벤토리에 추가되는지 확인한다.
- 은빛 털과 접힌 잎이 단서 수첩에 기록되는지 확인한다.

### P5 — 달빛 온실

- 달빛 손잡이를 선택하지 않고 문을 눌러 안내를 확인한다.
- 손잡이를 선택해 문을 열고 개방 연출 중 중복 입력이 막히는지 확인한다.
- 2개 화단을 선택해 더 많은 화단이 가능하다는 안내를 확인한다.
- 4개 화단을 선택해 별 에너지가 남는다는 안내를 확인한다.
- 6개 화단에서 별 3개·달 4개씩 배치되는지 확인한다.
- 씨앗과 포포 발견 카드가 충분히 읽을 수 있게 남아 있는지 확인한다.
- 따뜻한 이끼와 감싼 씨앗 단서를 수첩에서 확인한다.

### 최종 추리와 결말

- 씨앗 발견 직후 최종 추리가 강제로 덮이지 않는지 확인한다.
- `사건 해결하기` 버튼을 눌러 최종 추리를 시작한다.
- 첫 번째 가설을 선택해 발자국의 시간 순서 피드백을 확인한다.
- 벌점 없이 다시 선택할 수 있는지 확인한다.
- 두 번째 가설을 선택해 정답으로 판정되는지 확인한다.
- 씨앗 귀환과 별빛 꽃 개화 연출이 자연스럽게 이어지는지 확인한다.
- 연출 시작 약 1초 뒤 건너뛰기 버튼이 동작하는지 확인한다.
- 포포가 씨앗을 보호했다는 결말 대사가 이해되는지 확인한다.
- `+110 XP`, 완료 횟수와 꽃숲 성장 단계가 표시되는지 확인한다.
- 별정원으로 돌아간 뒤 Home 화면 수치가 실제로 갱신되는지 확인한다.

## 4. 앱 중단과 복귀

다음 구간에서 Chrome을 잠시 백그라운드로 보낸 뒤 다시 돌아온다.

1. P1 별가루 배치 중
2. 연못 발자국 선택 중
3. 온실 화단 선택 중
4. 최종 개화 연출 직전

확인 사항:

- 화면이 멈추거나 검게 변하지 않는다.
- 선택한 아이템과 해결한 퍼즐이 초기화되지 않는다.
- 입력 잠금이 영구적으로 남지 않는다.
- 효과음이 중복 재생되지 않는다.

## 7. 통과 기준

다음 조건을 모두 만족하면 Galaxy 태블릿 실기기 검증을 통과한 것으로 본다.

- 진행을 막는 오류 없이 시작부터 결말까지 완료
- P0~P5의 정답과 오답 피드백이 모두 정상
- 아이템이 잘못 소모되거나 중복 생성되지 않음
- 최종 추리 전에 발견 장면과 단서 수첩을 확인할 수 있음
- 경험치가 정확히 110 증가하고 완료 횟수가 1 증가
- 세로·가로 화면에서 주요 UI가 겹치거나 잘리지 않음
- 전체 플레이 시간이 대체로 8~12분 범위

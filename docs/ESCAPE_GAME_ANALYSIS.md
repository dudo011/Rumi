# Rumi 대표 방탈출 게임 분석서

- 문서 상태: 확정본
- 작성일: 2026-07-27
- 적용 대상: Episode 1 「사라진 별빛 씨앗」 재설계

---

## 1. 분석 목적

이 문서는 유명 게임의 외형을 모방하기 위한 자료가 아니다. Rumi의 핵심 사용자와 개발 환경에 맞는 2D 장면형 방탈출 게임을 만들기 위해 다음을 확정한다.

1. 재미있는 방탈출 게임이 호기심을 유지하는 방식
2. 장면·오브젝트·아이템·퍼즐·힌트·연출의 연결 구조
3. Flame으로 구현 가능하면서 재미를 훼손하지 않는 채택 요소

최종 질문은 다음과 같다.

> 초등학교 5학년 아이가 태블릿에서 약 10분 동안 스스로 관찰하고, 발견하고, 연결하고, 해결하고 싶게 만드는 장면은 어떻게 설계해야 하는가?

---

## 2. 공통 분석 기준

모든 작품을 다음 12개 항목으로 분석했다.

1. 첫 30초의 시선 유도
2. 장면 수와 이동 구조
3. 조사 가능한 오브젝트의 표현
4. 확대 조사 화면
5. 아이템 획득과 사용
6. 퍼즐의 선후관계
7. 이전 장면으로 돌아가게 만드는 이유
8. 정답 순간의 시각·음향 보상
9. 실패와 오답 처리
10. 힌트 제공 방식
11. 이야기 전달 방식
12. Flame 구현 가능성

### 구현 가능성 등급

| 등급 | 의미 |
|---|---|
| A | 현재 Flutter·Flame 구조에서 안정적으로 구현 가능 |
| B | 구현 가능하지만 독립 프로토타입 검증 필요 |
| C | 구현 비용에 비해 효율이 낮음 |
| 제외 | 사용자·세션 길이·기술 범위와 맞지 않음 |

### 채택 원칙

- 원작의 그래픽보다 플레이어가 느끼는 감정을 분석한다.
- 같은 감정을 단순한 2D 구현으로 줄 수 있는지 확인한다.
- 구현 과정에서 핵심 재미를 대체해야 하면 채택하지 않는다.
- 수학은 문제 화면이 아니라 장면과 장치의 규칙으로 사용한다.

# 4. 작품별 분석

## 4.1 The Room: Old Sins

### 구조와 재미

중앙 인형집이 전체 게임의 허브다. 플레이어는 인형집의 외부와 여러 방을 오가며 물체를 확대하고, 손잡이·다이얼·레버·슬라이더를 직접 조작한다. 한 방에서 얻은 부품이 다른 방을 열며, 작은 성공은 더 큰 기계 구조나 새로운 공간의 노출로 이어진다.

### 장면 설계

```text
인형집 전체
→ 특정 방
→ 방 안의 물체
→ 물체의 세부 장치
→ 숨겨진 내부 공간
```

전체 화면에서는 장소의 관계를 보고, 확대 화면에서는 한 장치에 집중한다. 모든 방을 처음부터 열지 않고 진행에 따라 탐색 범위를 넓힌다.

### 정답 연출

가장 중요한 강점이다.

1. 클릭·찰칵 같은 즉시 반응
2. 부품 이동과 연쇄 작동
3. 카메라가 변화한 위치에 집중
4. 새로운 단서·아이템·공간 공개

정답의 가치를 문구가 아니라 **세계의 물리적 변화**로 전달한다.

### Rumi 적용

| 요소 | 판단 | 등급 | 적용 방식 |
|---|---:|---:|---|
| 중심 장소를 허브로 사용 | 채택 | A | 중앙 정원에서 연못·온실·꽃숲 이동 |
| 전체→장면→확대 구조 | 채택 | A | 고정 장면과 확대 조사 화면 |
| 장치의 연쇄 작동 | 채택 | A | 이동·회전·투명도 효과와 효과음 |
| 다른 방의 부품 사용 | 채택 | A | 인벤토리와 상태 조건 연결 |
| 완전한 3D 회전 조사 | 제외 | 제외 | 퍼즐 자체를 2D로 설계 |
| 정밀 자유 회전 장치 | 제외 | C | 탭·드래그·제한 회전만 사용 |

**핵심 교훈:** 정답 메시지보다 내가 만진 물체 때문에 세계가 움직였다는 감각이 중요하다.

## 4.2 Cube Escape Collection·Samsara Room

### 구조와 재미

한정된 고정 2D 벽면을 반복 조사한다. 처음에는 평범했던 시계, 거울, 전화기, 액자가 새로운 아이템이나 정보가 생긴 뒤 다른 기능을 가진다. 장면 수가 적어 작은 변화를 쉽게 발견할 수 있다.

### 장면 설계

- 방을 약 4개의 벽면으로 나눈다.
- 각 벽면에는 강한 중심 오브젝트 하나를 둔다.
- 모든 장면을 빠르게 순환할 수 있어 기억 부담이 낮다.
- 진행 후 기존 장면의 색·모양·시간·기능이 변한다.

### 퍼즐 연결

```text
아이템 A로 장치 B 해제
→ 단서 C 획득
→ 처음 보았던 물건 D의 의미 재해석
```

같은 오브젝트를 한 번만 사용하지 않고, 상태가 바뀐 뒤 다시 조사하게 한다. 예상 밖의 장면 변화가 화려한 3D 없이도 강한 보상이 된다.

### Rumi 적용

| 요소 | 판단 | 등급 | 적용 방식 |
|---|---:|---:|---|
| 기억 가능한 4~6개 장면 | 채택 | A | 에피소드 주요 장면 수 제한 |
| 같은 장면의 상태 변화 | 채택 | A | 해결 전·후 이미지와 상호작용 변경 |
| 기존 오브젝트 재해석 | 채택 | A | 초반 장치가 후반 단서로 의미 변화 |
| 짧은 초현실적 변화 | 조건부 채택 | A | 별빛·꽃·그림자 연출 |
| 공포·잔혹 이미지 | 제외 | 제외 | 신비롭고 안전한 분위기로 변경 |
| 비논리적 아이템 조합 | 제외 | A | 형태와 상황으로 납득 가능한 인과관계 유지 |

**핵심 교훈:** 장면이 많아야 탐험이 되는 것이 아니다. 적은 장면이 여러 번 다른 의미를 가지면 더 깊은 탐험이 된다.

## 4.3 Adventure Escape Mysteries

### 구조와 재미

사건을 중심으로 여러 일러스트 장면을 이동하며 단서를 모으고 퍼즐을 해결한다. 이야기의 현재 목표가 명확하고, 모바일 화면에서도 중요 오브젝트가 알아보기 쉽다.

### 장면 설계

- 시작 직후 사건과 현재 목표를 짧게 제시한다.
- 중심 대상은 대비와 위치로 구분한다.
- 확대 퍼즐은 별도의 근접 화면으로 연다.
- 해결된 오브젝트는 사라지거나 상태가 변해 탐색 범위를 줄인다.

### 힌트와 오답

- 플레이어가 오래 막히지 않도록 힌트를 눈에 보이게 제공한다.
- 오답은 퍼즐 안에서 즉시 피드백하며 진행을 되돌리지 않는다.
- 현재 목표가 명확해 무작위 탭을 줄인다.

### Rumi 적용

| 요소 | 판단 | 등급 | 적용 방식 |
|---|---:|---:|---|
| 짧고 명확한 사건 목표 | 채택 | A | 씨앗이 사라진 상황과 조사 이유 제시 |
| 모바일에서 읽히는 오브젝트 | 채택 | A | 최소 터치 영역과 대비 기준 설정 |
| 조사 화면과 퍼즐 보드 분리 | 채택 | A | 확대 퍼즐을 별도 장면으로 표시 |
| 사건 증거가 되는 퍼즐 | 채택 | A | 수학 결과가 추적 정보가 되게 설계 |
| 픽셀 단위 숨은그림찾기 | 제외 | A | 작은 물건 찾기를 핵심 난이도로 사용하지 않음 |
| 힌트 과금 구조 | 제외 | 제외 | 단계별 무료 힌트 사용 |

**핵심 교훈:** 사건의 목적을 이해하면 플레이어는 무작정 누르지 않고 단서를 찾기 위해 관찰한다.

## 4.4 Dark Dome Hidden Town 시리즈

### 구조와 재미

각 작품은 하나의 사건을 완결하지만 모든 사건이 Hidden Town의 공통 세계와 연결된다. 고정된 2D 일러스트 장면을 오가며 도구를 수집하고, 장치와 암호를 풀고, 짧은 이야기 조각으로 세계의 비밀을 확장한다.

### 장면 이동

- 각 방을 한 장의 일러스트로 표현한다.
- 문·계단·통로를 누르면 다른 장면으로 이동한다.
- 이동 지점이 실제 공간 배치와 일치해 장소를 기억하기 쉽다.
- 방마다 아직 풀지 못한 장치를 한두 개 남겨 다른 장소에서 도구를 얻은 뒤 돌아오게 한다.

### Rumi 적용

| 요소 | 판단 | 등급 | 적용 방식 |
|---|---:|---:|---|
| 고정 2D 장면과 공간형 이동 | 채택 | A | 중앙 정원 주변 장소를 방향성 있게 연결 |
| 독립 사건과 공통 세계관 | 채택 | A | 씨앗 사건은 끝내고 별정원의 큰 비밀을 남김 |
| 미해결 장치를 남긴 왕복 | 채택 | A | 장면마다 잠긴 요소 최대 1개 |
| 일러스트 교체 중심 연출 | 채택 | A | 공간 변화의 핵심 수단으로 사용 |
| 다중 시간대·인물 전환 | 보류 | B | 첫 에피소드 범위를 넘음 |
| 공포·잔혹 표현 | 제외 | 제외 | 대상 사용자에 맞지 않음 |

**핵심 교훈:** 한 사건은 완결하되 더 큰 질문 하나를 남겨야 다음 방문이 생긴다.

## 4.5 Glitch Games 작품군

분석 대상은 Forever Lost와 Another Tomorrow 등이다.

### 구조와 재미

여러 장소를 이동하며 단서와 기록을 사진으로 남기거나 인벤토리에 보관한다. 멀리 떨어진 장면의 정보가 연결되는 경우가 많아 게임 안의 기억 보조 시스템이 중요하다.

### 장점

- 종이에 따로 적지 않아도 이전 장면의 숫자·모양·배열을 확인할 수 있다.
- 사진이나 기록은 “이 정보가 중요하다”는 플레이어의 판단을 보존한다.
- 장면 간 연결이 강한 깨달음을 만든다.

### 위험

- 이동 경로가 길면 왕복이 지루해진다.
- 단서가 많으면 추리보다 정보 관리가 어려워진다.
- 어린 사용자는 현재 풀 수 있는 퍼즐과 나중 퍼즐을 구분하기 어렵다.

### Rumi 적용

| 요소 | 판단 | 등급 | 적용 방식 |
|---|---:|---:|---|
| 중요한 단서 자동 기록 | 채택 | A | 별지기 수첩에 그림과 짧은 문장 저장 |
| 장면 간 정보 연결 | 채택 | A | 한 장소의 배열을 다른 장치 규칙으로 사용 |
| 축소형 인벤토리 | 채택 | A | 하단 표시, 선택할 때만 확장 |
| 직접 사진 촬영 | 보류 | A | 첫 에피소드는 자동 기록으로 단순화 |
| 많은 장소의 장거리 왕복 | 제외 | A | 주요 장면 4~6개 안에서만 왕복 |
| 외부 메모가 필요한 암호 | 제외 | A | 수첩만으로 해결 가능한 정보량 유지 |

**핵심 교훈:** 장면 연결의 재미는 유지하되 기억력과 메모 능력을 시험하지 않도록 게임이 핵심 정보를 보관해야 한다.

# 5. 공통적으로 확인된 재미의 구조

## 5.1 퍼즐 개수보다 인과관계가 중요하다

```text
관찰
→ 의심
→ 조작
→ 즉각적인 반응
→ 새로운 정보
→ 이전 장면 재해석
→ 더 큰 변화
```

퍼즐은 반드시 방, 물건 또는 사건을 변화시켜야 한다.

## 5.2 첫 성공은 추리보다 조작이어야 한다

첫 30초에는 복잡한 계산이나 왕복을 요구하지 않는다.

- 빛나는 물건을 누른다.
- 떨어진 부품을 끼운다.
- 손잡이를 당긴다.
- 덮개가 열리며 첫 단서가 나온다.

이를 통해 “관찰하고 만지면 세계가 반응한다”는 규칙을 학습시킨다.

## 5.3 장면마다 중심 오브젝트 하나가 필요하다

- 중심 오브젝트 1개
- 현재 조사 가능한 보조 오브젝트 1~2개
- 분위기용 배경 오브젝트
- 나중에 활성화되는 오브젝트 최대 1개

같은 중요도의 물건을 많이 배치하면 무작위 탭이 발생한다.

## 5.4 미해결 상태가 눈에 보여야 한다

- 열쇠구멍은 있지만 열쇠가 없다.
- 홈이 비어 있지만 맞는 조각이 없다.
- 버튼은 있지만 전원이 없다.
- 흔적은 있지만 다음 방향이 보이지 않는다.

가시적인 미완성 상태가 다음 행동의 목적이 된다.

## 5.5 아이템은 모양으로 용도를 암시한다

별 모양 조각과 별 모양 홈처럼 설명문 없이도 연결할 수 있어야 한다. 첫 에피소드에서는 서로 관련 없어 보이는 물건의 억지 조합을 사용하지 않는다.

## 5.6 왕복에는 이유가 있어야 한다

- 새 아이템으로 기존 잠금장치를 열 수 있게 됨
- 새 단서로 이전 무늬를 이해하게 됨
- 다른 장소의 변화가 첫 장소에도 영향을 줌
- 이야기상 새 증거를 확인해야 함

돌아갔을 때 변화가 없으면 왕복은 피로가 된다.

## 5.7 정답은 장면 변화로 보상한다

정답 직후 다음 세 가지를 결합한다.

1. 즉시 반응: 클릭·빛·짧은 진동
2. 진행 연출: 물체 이동·덮개 열림·카메라 집중
3. 결과 공개: 단서·아이템·새 공간 등장

“정답입니다” 팝업은 사용하지 않는다.

## 5.8 힌트는 관찰 범위를 좁힌다

1. 목표 힌트: 지금 무엇을 해결해야 하는가
2. 위치 힌트: 어느 장면이나 물건을 다시 봐야 하는가
3. 행동 힌트: 어떤 아이템이나 규칙을 사용해야 하는가

가능하면 최종 입력값은 직접 제공하지 않는다.

## 5.9 이야기는 플레이를 멈추지 않는다

이야기는 장면 변화, 발견 물건, 짧은 대사, 수첩의 한두 문장과 결말의 반전으로 전달한다. 긴 설명 화면을 연속 표시하지 않는다.

# 6. Rumi 장면 설계 규칙

- 주요 장면: 4~6개
- 확대 장면: 3~5개
- 동시에 해결 가능한 핵심 퍼즐: 최대 2개
- 보유 아이템: 최대 4개
- 모든 주요 장면은 최소 초기·변화 두 상태를 가짐
- 핵심 장면은 초기·부분 해제·완료 세 상태까지 허용
- 확대 화면에서 뒤로 가면 정확히 이전 장면으로 복귀
- 조사 대상으로 보이는 물건은 터치 시 반드시 반응
- 핵심 터치 영역은 보이는 이미지보다 넓게 설정
- 작은 물건 찾기를 핵심 난이도로 사용하지 않음

- 연쇄 애니메이션: 중복 입력 방지 확인 필요
- 짧은 타이밍 퍼즐: 사용자 부담 확인 필요

- 자유로운 3D 물체 회전
- 정밀 물리 시뮬레이션
- 반사신경 중심 퍼즐
- 긴 계산식 직접 입력
- 미세한 색 차이 구분
- 외부 메모가 필요한 복잡한 암호
- 무작위 시행착오 장치

# 9. Episode 1 적용 결론

## 유지 요소

- 중앙 정원
- 빈 별받침대
- 긁힌 흔적과 별가루
- 발자국
- 분수대 상자
- 열쇠
- 포포가 씨앗을 지켜주었다는 결말
- 약수와 배수 주제

## 재설계 흐름

```text
중앙 정원에서 사건과 미해결 장치 확인
→ 연못·온실·꽃숲을 선택적으로 조사
→ 단서 또는 아이템 획득
→ 한 장면의 정보로 다른 장치 작동
→ 중앙 정원의 큰 상태 변화
→ 숨겨진 공간에서 최종 증거 발견
→ 증거를 연결해 포포의 행동 이해
→ 씨앗 회복과 다음 사건의 작은 단서
```

## 반드시 포함할 경험

1. 시작 30초 안의 간단한 조작 성공
2. 처음 본 장소로 돌아왔을 때 눈에 띄는 변화
3. 아이템 모양을 보고 사용처를 추측
4. 서로 다른 장면의 단서를 연결
5. 수학 규칙으로 실제 물건을 배치
6. 장치의 연쇄 작동 보상
7. 정원이 밝아지는 최종 보상
8. 다음 에피소드로 이어지는 미해결 질문 하나

## 포함하지 않을 경험

- 연속 객관식 문제
- 안내문 순서대로 정해진 물건만 누르는 진행
- 모든 핵심 오브젝트를 처음부터 활성화
- 획득 즉시 자동 사용되는 아이템
- 단서 개수만 채우면 열리는 최종 단계
- 수학과 사건이 별도로 진행되는 구조

# 10. Flame 예비 구현 가능성

본격적인 검증은 다음 단계에서 별도 수행한다.

| 기능 | 판단 | 구현 수단 |
|---|---:|---|
| 고정 2D 장면 | 가능 | World·PositionComponent·SpriteComponent |
| 오브젝트 탭 | 가능 | TapCallbacks |
| 드래그 퍼즐 | 가능 | DragCallbacks |
| 장면 이동 | 가능 | RouterComponent 또는 상태 기반 교체 |
| 확대 조사 | 가능 | Route·Camera zoom·확대 컴포넌트 |
| 인벤토리 | 가능 | Flutter Overlay 또는 투명 Route |
| 힌트·대화 | 가능 | Flutter Overlay |
| 물체 이동·회전·확대 | 가능 | Move·Rotate·Scale Effect |
| 페이드와 빛 변화 | 가능 | Opacity·Color Effect |
| 장면 상태 유지 | 가능 | 에피소드 상태 모델 |
| 효과음·배경음 | 가능 | flame_audio 추가 필요 |
| 완전한 3D 자유 회전 | 부적합 | 범위에서 제외 |
| 복잡한 실시간 물리 | 부적합 | 범위에서 제외 |

분석에서 채택한 핵심 재미는 3D 그래픽 자체가 아니라 탐색 범위의 단계적 개방, 장면 간 연결, 아이템의 인과관계, 상태 변화와 정답 직후의 연쇄 연출이다. 이 요소들은 Flame의 2D 기능으로 구현할 수 있으므로 현재 엔진을 유지한다.

# 11. 최종 채택 원칙

1. 에피소드의 중심은 문제 풀이가 아니라 장면 탐색이다.
2. 첫 30초에는 즉시 이해되는 조작 성공을 제공한다.
3. 주요 장면은 4~6개로 제한한다.
4. 장면마다 강한 중심 오브젝트 하나를 둔다.
5. 조사 대상으로 보이는 물건은 반드시 반응한다.
6. 모든 주요 장면은 진행에 따른 시각적 변화를 가진다.
7. 퍼즐 정답은 새 정보나 공간 변화로 이어진다.
8. 아이템은 형태와 상황으로 사용처를 추론할 수 있어야 한다.
9. 왕복에는 새 정보·아이템·변화가 있어야 한다.
10. 한 장면의 단서가 다른 장면에서 최소 한 번 사용된다.
11. 수학은 분류·배치·관찰·추론 규칙으로 사용한다.
12. 오답은 벌점 없이 구체적인 피드백을 제공한다.
13. 힌트는 목표→위치→행동 순서로 제공한다.
14. 해결 순간에는 소리·움직임·결과 공개를 결합한다.
15. 사건은 끝내되 다음 에피소드의 질문 하나를 남긴다.

## 14. 최종 결론

Rumi는 특정 게임 하나를 복제하지 않는다.

- The Room에서 **조작 후 세계가 움직이는 만족감**을 가져온다.
- Cube Escape에서 **적은 장면을 반복해서 새롭게 보게 하는 구조**를 가져온다.
- Adventure Escape Mysteries에서 **명확한 사건 목적과 모바일 가독성**을 가져온다.
- Dark Dome에서 **2D 공간 이동과 독립 사건·연결 세계관**을 가져온다.
- Glitch Games에서 **장면 간 단서 연결과 기억 보조**를 가져온다.

완전한 3D 조작, 복잡한 물리, 과도한 암호, 공포 표현과 긴 장거리 왕복은 채택하지 않는다.

Rumi Episode 1의 목표 경험은 다음과 같다.

> 아이가 정답 버튼을 찾는 것이 아니라, 정원을 살펴보고 물건을 만지며 변화를 만들고, 서로 떨어진 단서를 연결해 별빛 씨앗의 행방을 스스로 밝혀내는 2D 장면형 방탈출 게임.
